### Data Flow
- `ApprovalLedgerTab` calls `api.get('/requirements/:id/events')` → backend returns `{ success: true, data: Event[] }`
- `AuditSummaryTab` calls `api.get('/requirements/:id/audit-summary')` → backend returns `{ success: true, data: RequirementAuditSummary }`
- Both refresh on `requirementId` prop change AND have a manual "刷新记录" button
- No WebSocket or polling

### Event Display Design (ApprovalLedgerTab)
- **Timeline** (Ant Design `<Timeline>`) sorted by createdAt ascending
- Each item shows:
  - **Event type** — Chinese label (e.g. `WORKFLOW_ADVANCED` → `推进工作流`) with colored tag
  - **Time** — dayjs format `YYYY-MM-DD HH:mm:ss`
  - **Actor** — name + type badge
  - **Status transition** — `fromStatus → toStatus` (when both non-null)
  - **Step transition** — `fromStep → toStep` (when both non-null)
  - **Assignee change** — `fromAssigneeId → toAssigneeId`
  - **Reason code** + **Reason text**
  - **Related report** / **Related transition** links
- Collapsible **"查看详情"** for technical fields (metadata, evidence, stateVersion, correlationId, source)
- **Backend already sanitizes sensitive keys** (token, password, secret, authorization, etc.)
- Evidence/metadata shown as safe key-value pairs (not raw JSON dump)

### Audit Summary Design (AuditSummaryTab)
- **Stats Section** (Ant Design `<Descriptions>` or `<Statistic>` cards):
  - 推进次数 (WORKFLOW_ADVANCED count)
  - 驳回次数 (WORKFLOW_REJECTED count)
  - 报告批准次数 (REPORT_APPROVED count)
  - 报告驳回次数 (REPORT_REJECTED count)
  - 门禁拦截次数 (GUARDRAIL_BLOCKED count)
- **Cycle Summary Section** (from backend `cycleSummary`):
  - 是否存在审批循环 (`suspectedLoop`)
  - 重复驳回步骤 (`sameStepMaxRejectCount`)
  - 高频原因代码 (`loopReasons`)
- **Timeline Section**: Quick summary list from backend `timeline[]`

### State Handling
| State | Behavior |
|-------|----------|
| Loading | `<Spin />` centered |
| Empty (no events) | "暂无审批流水记录。审批流水账于 2026 年 7 月 11 日 21:10 上线，此前的历史记录未回填。" |
| 403 Forbidden | "你没有权限查看该需求的审批流水账。" |
| 404 Not Found | "需求不存在" |
| 401 | Global axios interceptor → redirect to `/login` |
| 5xx / Network | "加载异常，请稍后重试" |
